# Симисторный регулятор мощности (одноканальный)

Полный цикл разработки устройства под сетевую нагрузку: схема → печатная
плата в KiCad → параметрический корпус во FreeCAD → файлы для 3D-печати.
Регулятор рассчитан на длительную работу с током до 4 А.

![Плата, 3D-вид](build/img/board_3d_top.png)
![Устройство в корпусе](build/img/enclosure_render.png)

> ⚠️ **Безопасность.** Устройство работает с сетевым напряжением 220 В.
> Повторяйте только при наличии опыта работы с силовой электроникой.
> Изоляция спроектирована по правилам усиленной изоляции, но готовое
> изделие требует проверки перед эксплуатацией.

---

## Возможности

- Управление активной нагрузкой до **4 А длительно** (симистор
  **BTA416Y-800C**, 3Q Hi-Com, с изолированным фланцем)
- Коммутация в момент перехода через ноль (**zero-cross**) — без
  импульсных помех в сеть
- Гальваническая развязка сетевой и низковольтной частей (оптроны
  **MOC3052**)
- ЖК-дисплей **1602 с I2C** и трёхкнопочное меню
- Датчик температуры по **1-Wire** с TVS-защитой на входе
- Питание МК от изолированного модуля **IRM-10-5** (5 В)
- Корпус для 3D-печати, генерируется скриптом под конкретную плату
- Разъём программатора (SWIO, +5V, GND, RX, TX) для прошивки и отладки

## Технические характеристики

| Параметр                | Основной вариант (3 А)           | Запасной (4 А)   |
| ----------------------- | -------------------------------- | ---------------- |
| Плата                   | 80 × 70 мм, 2 слоя, 1,6 мм       | то же            |
| Корпус                  | 87,9 × 75,8 × 46,1 мм            | 101 × 76 × 46 мм |
| Ток длительно\*         | 2,8 А (макс. потери по даташиту) | 4,1 А            |
| Радиатор                | ≈ 22 К/Вт                        | ≈ 14 К/Вт        |
| Изоляция сеть–НН        | ≥ 6,6 мм (усиленная)             | то же            |
| Функциональная изоляция | ≥ 2,5 мм                         | то же            |

\* При температуре воздуха в корпусе 40 °C и кристалле ≤ 110 °C, по
максимальным потерям BTA416Y-800C из даташита.

## Аппаратная часть

### Компоновка платы

- Все компоненты на верхней стороне; нижняя сторона чистая, плата
  лежит на стойках корпуса.
- **Сетевая часть** — левая колонка (симистор с радиатором, клеммники
  сети и нагрузки).
- **Низковольтная часть** — правая сторона (МК, дисплей, кнопки, датчик).
- Между ними — полоса развязки, через которую нет меди; оптроны
  установлены поперёк неё.
- Все клеммники на нижней кромке, провода вставляются через окна стенки
  корпуса.

### ЭМС и разводка

- Сплошная земля на нижнем слое в низковольтной части; верхний слой
  залит землёй; слои связаны 27 переходными.
- Питание МК — дерево без петель: `IRM → C201 → шина → МК / периферия`.
- Датчик: TVS-диод стоит первым от клеммника, его земля — переходным
  рядом.
- Конденсатор фильтра детектора нуля расположен у выхода оптрона.
- Силовые пути 4 А разведены дорожками 2 мм.

### Правила изоляции (проверены DRC)

| Правило                        | Минимум | Фактически |
| ------------------------------ | ------- | ---------- |
| Сеть — НН (усиленная изоляция) | 6,0 мм  | ≥ 6,6 мм   |
| Фаза / ноль / нагрузка (250 В) | 2,5 мм  | ≥ 2,5 мм   |
| Прочие сетевые цепи            | 1,0 мм  | ≥ 1,0 мм   |

**DRC: 0 ошибок, 0 неразведённых цепей.** Сверка со схемой — 0 расхождений.

## Корпус

Корпус строится **автоматически по файлу платы** скриптом `case.py`
(FreeCAD 1.1): считываются контур, отверстия, клеммники, симистор и
цепи сети/НН. Затем скрипт проверяет посадку и зазоры и выгружает
STL и STEP.

- Высота над платой 36 мм — рассчитывается по карте глубин всего, что
  висит на крышке (дисплей с переходником, провода, держатель, кнопки).
- Зазоры от сетевых деталей — не меньше **6 мм**, от остальных — 1 мм.
- Вентиляция: вход через щели левой стенки на уровне рёбер радиатора,
  выход — под дисплеем. Щели 1,6 мм (щуп ⌀2,5 не проходит).
- Крепление платы — 4 самореза в стойки дна; крышка — 4 самореза сбоку.
- Возможна подвеска на стену (два ключевых паза в низковольтной зоне).

### Детали для печати

| Файл                | Деталь            | Ориентация |
| ------------------- | ----------------- | ---------- |
| `base.stl`          | основание         | дном вниз  |
| `lid.stl`           | крышка            | лицом вниз |
| `button_holder.stl` | держатель кнопок  | плоскостью |
| `button_cap.stl`    | толкатель (3 шт.) | верхом     |

**Материал:** ABS/ASA или негорючий ABS/PC (V-0) — радиатор греется
до ~90 °C.

## Сборка из исходников

Плата **не правится напрямую** — она собирается из частей:

```bash
cd hw_1ch_v2

# Сборка файла платы из частей
head -n -2 build/placed.kicad_pcb > regulator1.kicad_pcb
cat routes/*.sexp >> regulator1.kicad_pcb
printf '\t(embedded_fonts no)\n)\n' >> regulator1.kicad_pcb

# Проверка правил проектирования
kicad-cli pcb drc --refill-zones --save-board \
    --severity-error -o build/drc_err.rpt regulator1.kicad_pcb
```
